# 遼の脱出記録 — 4545

スマートフォン・PCのブラウザで遊べる、オリジナルの脱出アドベンチャーです。

## 起動方法
1. ZIPを展開します。
2. `index.html` をSafari / Chrome / Edgeなどで開きます。
3. 画面の「部屋をくまなく調べる」から探索を開始してください。

サーバーやインストールは不要です。セーブはブラウザの `localStorage` を使用します。

## 収録要素
- 主役：遼（@sobaabura_ を題材にしたファンゲーム風の架空ストーリー）
- パキスラのメガネ：隠された文字を発見
- ぐーばのラジオ：周波数パズルと音声ヒント
- テオのPC：入力画面・ログイン・オフライン記録
- 破壊のハンマー：錠前や格子を破壊する選択肢
- 鍵の番号：4545
- 6エリア、持ち物、探索メモ、複数エンディング、セーブ／ロード、スマホ対応UI

## 注意
人物の写真や公式素材は含めず、イラスト風のオリジナル背景で構成しています。本人の写真を使いたい場合は、利用許可のある画像を別途ご用意ください。
